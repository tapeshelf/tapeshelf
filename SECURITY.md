# Security

If you've found a security problem, please don't open a public issue. Write to **contact@tapeshelf.com** with what you found and how to reproduce it.

You'll get an answer within a week. This is a small project without a bug bounty, but real reports get fixed quickly and credited if you'd like.

Please test on your own instance rather than on tapeshelf.com, and don't touch other people's data.

Only the newest version gets security fixes, so keep your instance updated with `./tapeshelf.sh update`.
